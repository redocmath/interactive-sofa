# interactive-sofa
> Mathematical Thesis Visualization via Graph Drawing: Tribute to Jineon Baek’s “Optimality of Gerver’s Sofa”

Motivated by [Romeo \& Juliet](https://www.behance.net/gallery/12000833/Romeo-Juliet) by Beetroot Design, we extract a dependency graph from Jineon Baek's paper, [Optimality of Gerver's Sofa](https://arxiv.org/abs/2411.19826), and embed it in the shape of Gerver's sofa. Furthermore, we focus on developing the embedded graph to provide insight into the paper's structure. This website is a part of the authors' Arthematics project.
